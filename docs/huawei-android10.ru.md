# Проверка COLDWIRE на Huawei с Android 10

[English](huawei-android10.md)

Подписанный APK установили на телефон Huawei с Android 10 (API 29) и ARM64. Контрольная сумма установленного APK совпала с релизной. После обновления до сборки `2232` исходный профиль остался выбранным. [Проверенный релиз](https://github.com/bgunn9in/COLDWIRE-amnezia-client/releases/tag/coldwire-spa-19e809562970)

Телефон подключался к тестовому входу A по USB, а прямые маршруты проходили по Wi-Fi. Узел A подтвердил допуск SPA. Каждый список загружали отдельно через **Заменить список с сайтами** в режиме **Напрямую**. Раздельное туннелирование приложений было выключено на протяжении всей проверки.

| Режим | Адрес в обоих списках | Контрольный адрес вне обоих списков | Адрес только в `ru-direct` |
| --- | --- | --- | --- |
| Полный туннель | B | B | B |
| `ru-services` | Wi-Fi | B | B |
| `ru-direct` | Wi-Fi | B | Wi-Fi |

Тестовый HTTP-сервер подтвердил, что запросы через туннель пришли с адреса выходного узла B. Для адресов в обход туннеля проверили, какой интерфейс выбрал Android. С каждым списком отдельный HTTP-сервер в локальной сети получил прямой запрос с телефона по Wi-Fi.

После проверки тестовый профиль удалили, а прежние настройки раздельного туннелирования восстановили.
