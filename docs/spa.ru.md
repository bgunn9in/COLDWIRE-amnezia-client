# Подключение в клиенте COLDWIRE

[English](spa.md)

## Установите приложение

Скачайте установщик и `SHA256SUMS.txt` из одного релиза. Перед запуском сверьте SHA-256 установщика с соответствующей строкой в списке. [Последний релиз](https://github.com/bgunn9in/COLDWIRE-amnezia-client/releases/latest)

| Устройство | Установщик |
| --- | --- |
| Windows x64 | `COLDWIRE-Windows-x64.msi` |
| Mac с Apple Silicon | `COLDWIRE-macOS.pkg` |
| Android 9 или 10, ARM64 | `COLDWIRE-Android-9-10-arm64-v8a.apk` |
| Android 11 и новее, ARM64 | `COLDWIRE-Android-11-plus-arm64-v8a.apk` |

Запустите MSI в Windows или откройте PKG в macOS. Оба установщика выпускаются без подписи. Само приложение в PKG подписано ad hoc. Если macOS блокирует установку, сначала сверьте контрольную сумму файла. [Инструкция Apple по Gatekeeper](https://support.apple.com/ru-ru/102445)

На Android откройте APK для своей версии системы. Если появится запрос, разрешите установку из браузера или файлового менеджера. Оба APK подписаны ключом COLDWIRE и используют имя пакета `org.amnezia.vpn.coldwire`. Если Android не обновляет раннюю тестовую сборку из-за другой подписи, сохраните профиль перед её удалением.

## Импортируйте свой профиль

1. Получите у администратора COLDWIRE файл `.vpn`. В нём находятся ключи VPN и SPA вашего устройства. Передавайте профиль только по закрытому каналу.
2. Откройте приложение. Нажмите **+**, затем выберите **Файл с настройками подключения**. Укажите файл `.vpn` и подтвердите импорт.
3. Выберите импортированный профиль и подключитесь. Проверьте внешний IPv4 на сайте, который открывается через VPN. Он должен совпасть с адресом выходного узла B. Сайт в списке прямых маршрутов увидит адрес провайдера.

В карточке конвертированного администраторского профиля может отображаться B. VPN при этом подключается к A по адресу из профиля. Управляйте SSH и допусками устройств через [панель COLDWIRE](https://github.com/bgunn9in/coldwire).

## Что происходит при подключении

Приложение отправляет узлу A SPA-запрос. A проверяет, что клиент владеет ключом устройства и получает ответы по своему адресу. Затем A открывает допуск для IPv4 отправителя на 120 секунд. Клиент запускает AmneziaWG и обычно обновляет допуск каждые 40 секунд. После смены публичного IPv4 новый адрес проходит проверку заново.

После подключения допуск продлевает VPN-служба на Windows, macOS и Android. Она работает и при закрытом окне. Служебные пакеты SPA идут к A вне VPN-туннеля.

## Если подключение не устанавливается

- Убедитесь, что запущена сборка COLDWIRE и выбран выданный для неё профиль. Попросите администратора проверить, действует ли ключ устройства.
- Если клиент долго показывает **Подключение**, проверьте доступность UDP-портов SPA и AmneziaWG на A. Сообщите администратору время попытки и укажите, если перед этим менялась сеть.
- В разделе журналирования выберите **Сохранить отчёт о соединении**. В JSON будут этап последней попытки, время и код ошибки. Адреса, имена устройств и ключи исключены. Если VPN подключён, приложение также проверит доступ к GitHub по HTTPS и сообщит об ошибке DNS, если имя не разрешилось.
- Чтобы получить журнал, в том же разделе выберите **Сохранить все логи**. Передайте журнал администратору. Файлы `.vpn` и ключи храните вне публичных отчётов.
