# COLDWIRE Amnezia VPN

[English](README.md)

COLDWIRE Amnezia VPN — форк AmneziaVPN. Перед подключением по AmneziaWG 3.1 приложение запрашивает SPA-допуск на входном узле COLDWIRE. Для подключения нужен `.vpn`, который выдал или конвертировал администратор реле.

- [Скачать клиент](https://github.com/bgunn9in/COLDWIRE-amnezia-client/releases/latest) для Windows x64, macOS (Intel и Apple Silicon) или Android 9/10 ARM64.
- [Установить приложение и подключиться](docs/spa.ru.md).
- [Развернуть реле или управлять устройствами](https://github.com/bgunn9in/coldwire).

GitHub Actions собирает установщики из ветки `feature/spa-admission`. В релизе есть контрольные суммы SHA-256 и ссылка на сборку. Приложение распространяется по [лицензии исходного проекта](LICENSE). [AmneziaVPN](https://github.com/amnezia-vpn/amnezia-client)
