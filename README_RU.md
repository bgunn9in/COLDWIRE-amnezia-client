# COLDWIRE Amnezia VPN

[English](README.md)

COLDWIRE Amnezia VPN — форк AmneziaVPN. Перед подключением по AmneziaWG 3.1 приложение запрашивает SPA-допуск на входном узле COLDWIRE. Для подключения нужен `.vpn`, который выдал или конвертировал администратор реле.

- [Скачать для Mac с Apple Silicon](https://github.com/bgunn9in/COLDWIRE-amnezia-client/releases/latest/download/COLDWIRE-macOS.pkg).
- [Скачать для Windows x64 или Android ARM64](https://github.com/bgunn9in/COLDWIRE-amnezia-client/releases/latest). Выберите APK для Android 10 или для Android 11 и новее.
- [Установить приложение и подключиться](docs/spa.ru.md).
- [Развернуть реле или управлять устройствами](https://github.com/bgunn9in/coldwire).

В COLDWIRE можно сохранить отчёт о соединении. На Windows и macOS VPN-служба продлевает допуск SPA и при закрытом окне приложения. [Руководство по подключению](docs/spa.ru.md)

В релизе есть контрольные суммы SHA-256 и ссылка на сборку GitHub Actions. Приложение распространяется по [лицензии исходного проекта](LICENSE). [AmneziaVPN](https://github.com/amnezia-vpn/amnezia-client)
